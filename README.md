# AI CV Management System

An AI-powered Resume Screening and Candidate Management System developed using Flask, Python, SQLite, and NLP concepts.

---

# Project Overview

The AI CV Management System automates the recruitment and resume screening process. The system allows HR teams to upload resumes, extract candidate details automatically, analyze skills, calculate candidate-job match scores, detect missing skills, and manage candidates efficiently through an analytics dashboard.

This project reduces manual recruitment effort and improves hiring efficiency using AI-based resume analysis.

# Project Workflow

1. HR logs into the system
2. Resume is uploaded in PDF format
3. System extracts candidate details
4. Skills are detected automatically
5. Candidate data is stored in database
6. Job description is entered
7. AI matching calculates match percentage
8. Missing skills are identified
9. Best candidate is recommended
10. Analytics dashboard displays reports
